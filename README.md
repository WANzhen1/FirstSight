## 概述

**一见（FirstSight）** 是一款专为老年人打造的 Android 桌面应用（Launcher）。应用围绕大字体、高对比度、防误触和全流程语音反馈进行设计，将日常高频需求（看时间天气、打电话、发起微信音视频通话、打开常用应用）整合到同一屏，减少层层菜单跳转带来的操作障碍。

---

## 主要功能

### 极简桌面与防误触
- 替代系统默认桌面，隐藏状态栏与导航栏，支持跟随系统、浅色、深色三种外观模式。
- 顶部大字号时间、日期、星期、农历与当前城市实时天气卡片；下方双列大头像联系人网格延伸至屏幕底部，常用应用最多展示 5 个（未配置时自动隐藏）。
- 隐藏式设置入口：需连续点击右上角电量图标 7 次并二次确认后才可进入设置页，避免误触修改配置。

### 一键通信与来电辅助
- **一键微信音视频 / 电话**：点击联系人弹出高对比度操作菜单，通过内置无障碍服务自动完成微信搜索并发起视频或语音通话；当无障碍流程检测到用户主动触屏或单步超时时立即中止并语音播报。
- **微信来电自动接听**：支持全屏来电界面、系统顶部无按钮通知横幅（自动点击展开后接听）、微信内悬浮来电条三种来电形态的自动接听；仅在真实进入通话接通界面后播报“已自动接听 XXX 的微信通话”。
  - **家人白名单精确匹配**：支持开启“仅接听已添加的家人”子开关，按联系人管理中设置的**微信昵称**精确匹配（自动过滤零宽字符），避免误接陌生人来电。
  - **自动免提**：支持“自动免提”子开关，在确认通话接通后自动开启扬声器免提（若当前已开启或使用蓝牙耳机则不会误关）。
- **挂断自动返回首页**：支持在设置中分别开启“微信语音/视频挂断自动返回首页”与“电话挂断自动返回首页”，通话结束、被拒接或主动取消后自动回到一见桌面（默认桌面模式下通过系统级 `GLOBAL_ACTION_HOME` 返回，兼容国产定制系统后台限制）。
- **断网与未插卡拦截**：发起微信音视频前检测可用网络，拨打电话前检测 SIM 卡状态（兼容双卡槽）；异常时直接拦截操作并播报语音与提示，不跳转无效页面。

### 全场景语音辅助（TTS）
- **信息播报**：点击首页时间天气卡片，连同当前所选/定位城市一起朗读时间、日期、农历与天气；支持整点报时、点击联系人朗读姓名、呼叫状态提示。
- **低电量语音报警**：支持在语音设置中开启低电量语音提醒及自定义阈值（`10% ~ 50%`），未充电且电量低于阈值时自动语音提醒及时充电。
- **音量独立控制与持久化**：支持调节语音播报音量并实时试听。

### 服药提醒与快捷工具
- **吃药 / 复诊提醒**：支持每天、周一至周五、周末或仅一次；可设置时间与备注，到点发送高优先级通知并语音播报，通知内可直接选择“已服用”或“10 分钟后再提醒”。
- **开机自动恢复**：提醒使用系统闹钟类精确排期，重启、改时间或应用更新后会自动重新排期。
- **首页快捷工具**：语音、手电筒、放大镜、计算器、系统闹钟五个入口；放大镜支持 1–8 倍数字变焦，手电筒直接控制闪光灯。
- **恶劣天气提醒**：暴雨、大雪、台风、高温、寒潮、大风、雾霾等天气会在首页显示提醒卡片，并每天最多语音播报一次。

### 固定语音指令
- 首页“语音”按钮支持：给联系人打电话、打开常用应用、播报天气/时间、打开提醒管理、打开快捷工具、开关手电筒、打开放大镜/计算器、设置系统闹钟。
- 只解析固定指令，不接入开放式大模型，避免老人说错时执行不可预期操作。

### 天气服务与城市设置
- **免 Key 公开天气接口**：采用腾讯天气公开 HTTPS 接口与公网 IP 定位接口，无需配置个人 API Key 即可开箱使用。
- **多级定位与全国城市覆盖**：自动定位模式下依次结合设备定位、Geocoder 逆地理编码、本地城市坐标表与公网 IP 定位获取所在城市；支持在天气设置页手动切换或搜索全国各省市，也可随时恢复自动定位。
- **首页简洁、设置页详尽**：首页仅展示当前天气，天气设置页展示当天实时详情及未来 7 天天气预报。

### 联系人与应用管理
- **联系人管理**：首次启动自动预置示例联系人；支持手动增删改、拍照或从相册设置头像、从系统通讯录批量导入（带去重与头像同步）、即时拖动排序决定首页展示顺序；电话号码为空时自动禁止勾选打电话。
- **应用管理**：扫描已安装应用（兼容小米读取应用列表权限）并配置首页常用应用。

### 首次启动权限门禁
- 引导页集中处理运行时权限（电话、通讯录、相机、位置、通知）、无障碍服务、悬浮窗、省电策略（无限制）与允许自启动；全部完成后方可点击“开始使用”进入桌面。

## 技术栈与架构

| 类别 | 技术选型 |
| :--- | :--- |
| 开发语言 | Kotlin `2.0.21` |
| UI 框架 | Jetpack Compose (BOM `2024.09.00`) + Material 3 |
| 架构模式 | MVVM + Repository (`StateFlow`) |
| 依赖注入 | Dagger Hilt `2.56.2` |
| 本地持久化 | Room `2.6.1` + DataStore Preferences `1.0.0` |
| 网络请求 | Retrofit `2.9.0` + OkHttp `4.11.0` + Gson `2.10.1` |
| 图片加载 | Coil `2.4.0` |
| 权限与工具 | XXPermissions `20.0`、Lunar `1.7.4`、Compose Reorderable `0.9.6` |
| SDK 版本 | `minSdk = 24` (Android 7.0) / `targetSdk = 35` (Android 15) |

### 目录结构

```text
app/src/main/java/
├── com/google/android/accessibility/selecttospeak/
│   └── SelectToSpeakService.kt      # 微信一键通话、来电自动接听、自动免提与挂断返回首页无障碍服务
└── tech/huangsh/firstsight/
    ├── FirstSightApp.kt             # Application 入口与图片加载配置
    ├── data/
    │   ├── local/                   # Room 数据库与 DAO
    │   ├── model/                   # 联系人、应用、设置与天气模型
    │   ├── remote/                  # 天气接口、IP 定位与全国城市表
    │   └── repository/              # 联系人、应用与设置仓库
    ├── di/                          # Hilt 全局依赖注入模块
    ├── service/wechat/              # 微信自动化状态机与节点定义
    ├── ui/
    │   ├── activity/                # 各功能页面 Activity
    │   ├── screens/                 # Compose 页面（首页/引导/联系人/应用/天气/语音/显示）
    │   └── theme/                   # 主题配色、样式令牌与内联矢量图标
    ├── utils/                       # 语音播报、电量、网络/SIM卡检测、Toast、权限与图片工具
    └── viewmodel/                   # 各模块 ViewModel
```

## 权限与适配说明

- **电话 / 通讯录 / 相机 / 存储**：用于拨打电话、导入系统联系人及拍摄或选择联系人头像。
- **位置 / 网络状态**：用于自动识别所在城市天气以及发起微信通话前的断网检测。
- **无障碍服务**：用于自动操作微信发起视频或语音通话。服务类保留 `com.google.android.accessibility.selecttospeak` 包名以兼容微信界面节点读取。
- **悬浮窗 / 省电无限制 / 自启动**：用于在国产定制系统下保持桌面与无障碍服务后台稳定存活。

## 本地构建

### 环境要求
- Android Studio Ladybug (2024.2.1) 及以上
- JDK 17（运行 Gradle），字节码编译目标为 Java 1.8
- Android SDK API 35

### 构建命令

```bash
# 克隆仓库
git clone https://github.com/GSJ8888/FirstSight.git
cd FirstSight

# 编译 Debug 包并运行单元测试
./gradlew :app:assembleDebug :app:testDebugUnitTest

# 编译 Release 包（已启用 R8 代码混淆与资源裁剪）
./gradlew :app:assembleRelease
```

> Release 打包签名需在本地自行配置 `.jks` 密钥库文件，请勿将签名私钥及 `local.properties` 提交至版本库。
